# 汉字拼音小径 趣味性增强计划（V2）

## 1. 目标与边界

- Game ID: hanzi_pinyin_path
- 游戏名: 汉字拼音小径
- 目标年龄: 6-12 岁
- 核心学习目标: 强化汉字与拼音（含声调）的双向映射与快速检索能力
- 目标单局时长: 5-10 分钟（保持与现状一致）

本计划聚焦“更好玩”，不改变当前四种玩法的学习主线，不做跨游戏大重构。

## 2. 需求澄清（当前假设）

因本轮未追加用户画像，本计划采用以下默认假设：

- 玩家以小学低中年级为主，偏好即时反馈与短回合奖励。
- 家长可接受轻量音效与柔和动画，不希望高噪声或过度刺激。
- 保持鼠标优先、键盘可选，不增加复杂操作门槛。

## 3. 候选趣味方案（2-4）

### 方案 A: 即时反馈强化（音效 + 视觉）

核心点：每次作答都“有手感”。

- 答对: 播放短促成功音 + 卡片轻微放大 + 星点粒子。
- 连击: 3 连击以上追加更亮的连击音与飘字。
- 答错: 柔和提示音 + 红色抖动（时长更短，避免挫败放大）。

优点:
- 开发成本低，中短期可落地。
- 与现有回合循环高度兼容。

风险:
- 若特效层级过多，可能干扰阅读与点击。

### 方案 B: 小径闯关节奏（里程碑奖励）

核心点：把 10 题回合拆成 3 个小目标，持续制造“快完成了”的期待。

- 题目 3/6/10 触发里程碑结算。
- 里程碑奖励星星或徽章，结果页展示“本局收集”。
- 错题重练模式也可掉落基础奖励，降低挫败感。

优点:
- 提升中途留存，适合儿童短注意力节奏。

风险:
- 需要补充奖励状态与 UI 文案管理。

### 方案 C: 角色陪伴反馈（轻叙事）

核心点：加入一个引导角色（如“小猫老师”）提供语音/文字鼓励。

- 连击和高分时触发角色台词。
- 答错时给简短策略提示（如“先看韵母”）。

优点:
- 情感化明显，适合低龄玩家。

风险:
- 需要更多素材与文案维护，实施成本较高。

## 4. 选型结论

本轮建议采用 A + B 组合，C 作为后续储备。

理由:
- A 直接满足“拼音选择正确时有音效和视觉效果”的核心诉求。
- B 提供中局目标与结果页收集感，显著提升“再来一局”动机。
- A + B 对当前架构侵入较小，便于分阶段上线与回滚。

## 5. 实施级需求定义

### 5.1 玩家体验与回合循环

现有流程保持不变：年级 -> 模式 -> 难度 -> 对局 -> 结果页。

新增体验层：

1. 即时反馈层
- 正确: success_sfx + scale_pop + sparkle。
- 高连击: combo_sfx + combo_banner（例如 3/5/8 连击阈值）。
- 错误: error_soft_sfx + short_shake + 正确答案提示。

2. 里程碑层
- 在第 3、6、10 题结算时触发 checkpoint 动画与奖励。
- 奖励类型: 星星（score 外显资源）+ 徽章（结果页展示）。

3. 结果页增强
- 新增“本局亮点”: 最长连击、最快答题、获得星星数。
- 保留“再来一局 / 练错题 / 返回菜单”。

### 5.2 题目与内容规则（logic.py）

不改变当前出题规则，仅新增“反馈事件与奖励事件”的纯逻辑函数，保证可单测。

建议新增 API:

- decide_feedback_tier(is_correct, streak, elapsed_ms, difficulty) -> str
  - 返回 normal_correct / fast_correct / combo_correct / wrong
- checkpoint_reward(round_index, accuracy_so_far, streak) -> RewardEvent
  - 返回星星数量与徽章类型（若满足条件）
- summarize_highlights(stats, fastest_ms, total_stars) -> HighlightSummary

约束:
- 奖励不反向影响正确判定。
- 奖励可影响显示分，但不影响基础学习统计（correct/wrong/accuracy）。

### 5.3 场景与交互（scene.py）

新增系统组件（scene 内部状态即可，无需跨模块依赖）：

- 音效通道管理:
  - 初始化 mixer，失败则自动静音降级（不抛异常）。
  - 每类音效节流，避免短时间重复叠音。
- 特效事件队列:
  - 每次提交答案后写入 fx_event，update(dt) 消费。
  - 特效生命周期 150-450ms，确保不遮挡题干。
- 连击飘字:
  - 达到阈值显示“连击 xN”。
- 里程碑弹层:
  - 第 3/6/10 题显示 0.6s 小弹层，不阻断后续输入超过 1s。

输入与可用性:
- 鼠标和键盘路径不变。
- 输入模式中 Backspace 继续用于删字符，不触发返回。

### 5.4 资源需求（Assets）

新增轻量音效（wav/ogg，单个 < 150KB，时长 80-400ms）：

- sfx_correct_1
- sfx_correct_fast
- sfx_combo
- sfx_wrong_soft
- sfx_checkpoint
- sfx_result_star

可选新增图形资源（非必须）：
- 徽章小图标 3-5 个（也可先用 pygame 基础图形绘制）。

## 6. 里程碑计划

### M1: 反馈事件逻辑化（1 天）

- 在 logic.py 新增反馈分层和里程碑奖励纯函数。
- 新增 dataclass: RewardEvent, HighlightSummary。
- 完成单测，确保固定 seed 下奖励触发可复现。

### M2: 音效框架与降级机制（1 天）

- 场景加载音效资源与播放路由。
- mixer 初始化失败时自动静音，保证 headless 不崩溃。

### M3: 视觉特效 MVP（1-2 天）

- 实现 scale_pop、short_shake、sparkle 粒子。
- 完成连击飘字与 checkpoint 弹层。

### M4: 结果页趣味增强（1 天）

- 展示星星、徽章、最佳时刻。
- 对接“练错题”回合，保证数据重置和展示正确。

### M5: 调参与验收（1 天）

- 调整音量、动画时长、阈值。
- 完整跑通测试、headless smoke 与手工体验走查。

## 7. 测试计划（unittest 风格）

新增或扩展测试文件: tests/test_hanzi_pinyin_path_logic.py

必测项:

1. 反馈分层
- 正确/错误/连击/快速答题映射到正确 feedback_tier。

2. 里程碑奖励
- round_index=3/6/10 时奖励触发。
- 不满足准确率或连击条件时不发放高阶徽章。

3. 可复现性
- 固定种子下，奖励事件序列一致。

4. 统计隔离
- 奖励变化不影响 correct_count/wrong_count/accuracy_percent。

5. 兼容性
- 无音效资源或 mixer 初始化失败时，逻辑层和场景主流程不抛异常。

## 8. 测试矩阵（摘要）

| 维度 | Easy | Medium | Hard |
|---|---|---|---|
| 模式一 汉字选拼音 | 正确音效 + 基础特效 | + 连击特效 | + 更紧时间下的快速答题特效 |
| 模式二 拼音选汉字 | 同上 | 同上 | 同上 |
| 模式三 连线配对 | 配对成功音效 | 连击里程碑触发 | 高密度配对下特效不卡顿 |
| 模式四 拼音输入 | 轻提示 + 声调反馈 | strict 下正确触发 | strict + 限时下组合反馈 |

附加矩阵:

- 输入路径: 鼠标点击 / 键盘快捷键 / 混合输入
- 运行环境: 本地有音频设备 / 无音频设备 / headless
- 回合状态: 正常回合 / 练错题回合

## 9. 验收标准

功能验收:
- 答对题目时，100% 触发可见视觉反馈；有音频设备时播放成功音效。
- 连击达到阈值时，触发更强反馈（音效或视觉至少一项升级）。
- 第 3/6/10 题能触发里程碑反馈并累计到结果页。
- 结果页展示本局星星与亮点数据。

技术验收:
- 现有核心统计与判题逻辑行为不回归。
- 全量 unittest 通过。
- headless smoke 可运行，不因音效初始化失败崩溃。

体验验收:
- 特效总时长不遮挡关键交互；玩家可在 1 秒内继续下一题。
- 错误反馈为“提示型”而非“惩罚型”，不明显增加挫败感。
